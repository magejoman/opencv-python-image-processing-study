# Part 0-5. 내적 = "닮은 정도 점수"

## 이 스텝의 목표
1. **내적**(두 수열을 곱해서 다 더하기)을 손으로 계산하고, 결과가 왜 **"얼마나 닮았나"**를 뜻하는지 설명할 수 있다.
2. **다른 주파수의 사인파끼리 내적하면 0**(직교)이라는 걸 숫자로 확인한다.
3. 02번 코드의 가중치 **0.3, −0.7, 0.5**를 합쳐진 신호에서 **내적만으로 다시 꺼낸다.** 이게 DFT의 정체예요.

0-5는 11단계로 나눠서 진행할게요.
```
① 문제 제기: 레시피 역추적          ② 내적의 정의와 손계산
③ 왜 "닮은 정도"인가 (부호 게임)    ④ 기하학: 화살표 사이 각도
⑤ 사인파끼리 내적: 직교성           ⑥ 왜 다른 주파수는 0이 될까
⑦ 실전: 02번 가중치 꺼내기          ⑧ 위상 문제: sin만으론 부족
⑨ 하나로 합치기 = DFT 공식          ⑩ 이미지 연결
⑪ 정리 + 셀프 체크 (Part 0 졸업)
```

## ① 문제 제기: 스무디를 보고 레시피 맞히기

[02.frequence_sum.py:10](../../chap09/02.frequence_sum.py#L10)은 이렇게 섞어요.
```python

```
섞는 건 쉬워요. 그럼 **반대로**, 섞인 결과 `g[4]`만 받았을 때 "1Hz는 0.3, 3Hz는 −0.7, 5Hz는 0.5만큼 들어 있다"를 알아낼 수 있을까요?

🧠 비유하면 스무디를 마셔 보고 "딸기 30%, 바나나 −70%(?), 망고 50%"를 맞히는 거예요. 필요한 건 **"이 스무디에서 딸기 맛이 얼마나 나는가"를 재는 측정기**예요. 그 측정기가 **내적**이에요.

## ② 내적의 정의와 손계산

### ②-1 정의
같은 길이의 수열 두 개를 **같은 자리끼리 곱하고, 전부 더해요.**
```
a · b = a[0]·b[0] + a[1]·b[1] + ... + a[N−1]·b[N−1] = Σ a[n]·b[n]
```

### ②-2 🔢 예시: a = [1, 2, 3], b = [4, 5, 6]
| n | a[n] | b[n] | a[n]·b[n] |
|---:|---:|---:|---:|
| 0 | 1 | 4 | 4 |
| 1 | 2 | 5 | 10 |
| 2 | 3 | 6 | 18 |
| | | **합** | **32** |

numpy에서는 `(a*b).sum()` 또는 `a @ b`로 계산하고, 둘 다 `32`가 나와요(실측).

> 💡 **DFT 코드를 다시 보세요:** `sum(g[n] * exp(k*n/N) for n in range(N))`
> **곱해서(`*`) 다 더하기(`sum`)**, 즉 내적이에요. DFT는 "신호와 회전자의 내적"이에요.

## ③ 왜 "닮은 정도"일까? 부호 게임

곱셈의 부호 규칙만 떠올리면 돼요.
- 같은 부호끼리 곱하면 **+** (둘 다 위, 또는 둘 다 아래) → 점수 **획득**
- 다른 부호끼리 곱하면 **−** (하나는 위, 하나는 아래) → 점수 **감점**

🔢 **기준 패턴 p = [+1, +1, −1, −1]과 비교 (실측)**

| 비교 대상 | 같은 자리 곱 | 합 (내적) | 해석 |
|---|---|---:|---|
| p 자신 [+1,+1,−1,−1] | +1, +1, +1, +1 | **+4** | 완전히 닮음 (최대) |
| −p [−1,−1,+1,+1] | −1, −1, −1, −1 | **−4** | 정반대 (뒤집힌 닮음) |
| [+1,−1,+1,−1] | +1, −1, −1, +1 | **0** | 무관 |
| [+1,−1,−1,+1] | +1, −1, +1, −1 | **0** | 무관 |

**내적 점수 읽는 법**
- **큰 양수**: 함께 오르내린다 = 닮았다
- **큰 음수**: 정반대로 오르내린다 = 뒤집으면 닮았다 (02번의 **−0.7**이 이 경우!)
- **0**: 서로 아무 관계가 없다. 이를 **직교**라고 해요.

## ④ 기하학: 내적 = 두 화살표가 얼마나 같은 방향인가

길이 2인 수열은 2D 화살표예요(0-3과 같은 그림).
```
a · b = |a| · |b| · cos(사이각)
```
🔢 **실측**
| a | b | 내적 | 사이각 |
|---|---|---:|---:|
| (3, 4) | (4, 3) | 3·4 + 4·3 = **24** | 16.26° (거의 같은 방향) |
| (3, 4) | (4, −3) | 3·4 + 4·(−3) = **0** | **90°** (직각 = 직교) |

```
     ↑
   4 ┤   ● (3,4)
     │  ╱
   3 ┤ ╱    ● (4,3)      ← 각도 16°: 내적 큼
     │╱  ╱
  ───┼─────────→
     │╲
  −3 ┤  ╲● (4,−3)        ← 각도 90°: 내적 0
```
길이 N짜리 수열은 **N차원 화살표**예요. 머릿속에 그릴 수는 없지만 규칙은 똑같아요. **내적이 0이면 N차원 공간에서 직각**이에요.

## ⑤ 사인파끼리 내적: 직교성

이제 수열 자리에 **샘플링된 사인파**를 넣어 볼게요(N = 8).

### ⑤-1 재료 (실측)
| n | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| sin1 (k=1) | 0 | .7071 | 1 | .7071 | 0 | −.7071 | −1 | −.7071 |
| sin2 (k=2) | 0 | 1 | 0 | −1 | 0 | 1 | 0 | −1 |
| sin3 (k=3) | 0 | .7071 | −1 | .7071 | 0 | −.7071 | 1 | −.7071 |
| cos1 (k=1) | 1 | .7071 | 0 | −.7071 | −1 | −.7071 | 0 | .7071 |

### ⑤-2 sin1과 각각을 곱하고 더하기 (실측)
| sin1 × ? | 같은 자리 곱 (n = 0..7) | 합 |
|---|---|---:|
| **sin1** (같은 주파수) | 0, .5, 1, .5, 0, .5, 1, .5 ← **전부 0 이상!** | **4** |
| sin2 | 0, .707, 0, −.707, 0, −.707, 0, .707 | **0** |
| sin3 | 0, .5, −1, .5, 0, .5, −1, .5 | **0** |
| cos1 (같은 주파수, 위상 90° 차이) | 0, .5, 0, −.5, 0, .5, 0, −.5 | **0** |

**발견**
1. **같은 사인파끼리** 곱하면 음수×음수도 양수가 되니까 **모든 곱이 0 이상**이에요. 합은 **N/2 = 4**예요.
2. **주파수가 다르면** +와 −가 **정확히 상쇄**돼서 0이에요.
3. **sin1과 cos1도 0**이에요. 같은 주파수라도 90° 어긋나면 직교예요. 이게 ⑧에서 문제가 돼요.

> 💡 **직교성 (chap09에서 가장 중요한 수학 성질):**
> 서로 다른 주파수의 사인/코사인은 내적하면 0이다.
> 그래서 섞여 있어도 **측정기 하나는 자기 주파수에만 반응하고 나머지는 못 본 척**해요.

## ⑥ 왜 다른 주파수끼리는 정확히 0이 될까?

### ⑥-1 곱셈 공식 하나
```
sin A · sin B = ½ · [ cos(A − B) − cos(A + B) ]
```
sin1 × sin2이면 A − B는 −1바퀴, A + B는 3바퀴짜리 각도가 돼요.
```
sin1 · sin2 = ½ · [ cos(1바퀴짜리) − cos(3바퀴짜리) ]
```
🧪 실측해 보면 ½(cos1 − cos3) = `[0, .707, 0, −.707, 0, −.707, 0, .707]`이고, ⑤-2의 sin1×sin2 행과 **똑같아요.**

### ⑥-2 그런데 cos를 "정수 바퀴" 동안 더하면 0이에요
0-4 ⑨의 그림을 떠올려 보세요. 원 위에 **골고루 퍼진 화살표**를 이어 붙이면 제자리로 돌아와요. 그 그림자(cos)도 +와 −가 정확히 같은 양만큼 있어서 **합이 0**이에요.

| 경우 | A − B | A + B | 합 |
|---|---|---|---|
| 같은 주파수 (k = m) | **0바퀴 → cos 0 = 1이 N번 → N** | 2k바퀴 → 0 | ½(N − 0) = **N/2** |
| 다른 주파수 (k ≠ m) | 정수 바퀴 → 0 | 정수 바퀴 → 0 | ½(0 − 0) = **0** |

**같은 주파수일 때만** A − B = 0이 돼서 "안 도는 성분"이 생기고, 그게 쌓여요. 0-4 ⑨ "같이 돌면 멈춰 보인다"를 실수 버전으로 다시 본 거예요.

> ⚠️ 조건: **N개 샘플 안에 정수 바퀴**가 들어가야 정확히 0이 돼요. 그래서 DFT는 k를 "N샘플 동안 k바퀴"(정수)로 정해요. 정수가 아닌 주파수(예: 2.5바퀴)는 여러 칸으로 번지는데, 이걸 **누설(leakage)**이라고 해요. Part 2에서 잠깐 볼게요.

```

              ├─▶ [sin4 측정기] ─▶ 0    ÷8 ─▶ 0

```
**측정기를 k = 0, 1, 2, …, N−1 전부에 대해 한 번씩 대는 것 = DFT**예요.

## ⑧ 위상 문제: sin 측정기만으로는 부족해요

### ⑧-1 🧪 함정 실험: 신호가 cos라면?
`h = 0.6·cos(2Hz)`에 sin 측정기를 대면:
```
Σ h · sin2 = 0.0    ← 0.6이 있는데 "없다"고 나옴! (⑤의 sin1 ⟂ cos1과 같은 이유)
Σ h · cos2 = 4.8    → ÷8 = 0.6 ✅
```
실제 신호는 위상이 제각각이에요. sin 측정기 하나로는 90° 어긋난 성분을 못 봐요.

### ⑧-2 해결: sin 측정기 + cos 측정기를 둘 다 대요
`h = 0.6·sin(2Hz + 30°)`처럼 위상이 섞인 경우(실측):

| 측정기 | 내적 | 0-1 ⑦의 예측 (N/2)·A·cos φ, (N/2)·A·sin φ |
|---|---:|---|
| sin2 | 4.1569 | 8 × 0.6 × cos 30° = **4.1569** ✅ |
| cos2 | 2.4000 | 8 × 0.6 × sin 30° = **2.4000** ✅ |

이 두 숫자를 0-3 ③처럼 화살표로 보면:
```
진폭 = √(4.1569² + 2.4²) / 8 = 4.8 / 8 = 0.6     ✅
위상 = atan2(2.4, 4.1569)              = 30°    ✅
```
**측정기 두 개(sin, cos) = 숫자 두 개 = 복소수 하나**예요. 0-1 ⑦부터 예고한 내용이 여기서 완성돼요.

## ⑨ 하나로 합치기: 이게 DFT 공식이에요

sin 측정기와 cos 측정기를 따로 대지 말고, 0-4의 **회전자** 하나로 한 번에 대면 돼요.
```
e^{−jθ} = cos θ − j·sin θ                (0-4: 오일러, 시계 방향)

Σ g[n] · e^{−j2πkn/N}
= Σ g[n]·cos(2πkn/N)  −  j · Σ g[n]·sin(2πkn/N)
  └──── cos 측정기 ───┘       └──── sin 측정기 ───┘
         = 실수부                    = −(허수부)
```
이게 **DFT 공식**이에요.
```
G[k] = Σ_{n=0}^{N−1} g[n] · e^{−j2πkn/N}
```

🧪 **확인: ⑦의 g를 `np.fft.fft`에 넣으면 (실측)**
```
G[0] =  0            G[1] = −2.4j       G[2] = 0
G[3] = +5.6j         G[4] = 0           G[5] = −4.0j
```
| k | sin 측정값 (⑦-3) | G[k] | 관계 |
|---:|---:|---|---|
| 1 | 2.4 | −2.4j | 허수부 = −(sin 측정값) ✅ |
| 3 | −5.6 | +5.6j | ✅ |
| 5 | 4.0 | −4.0j | ✅ |

실수부(cos 측정값)는 전부 0이에요. g가 sin만으로 만들어졌으니까요. ⑧-2의 위상 섞인 h도 `np.fft.fft(h)[2] = 2.4 − 4.1569j`로, 실수부 = cos 측정값, 허수부 = −(sin 측정값)이 정확히 맞아요.

> 💡 **Part 0 전체를 한 줄로:**
> **DFT = 신호에 "k바퀴짜리 도는 점"을 측정기로 대서(내적), 각 주파수가 얼마나 크고(크기) 어디서 출발했는지(각도)를 복소수 하나로 기록하는 것.**

## ⑩ 이미지 연결: 내적은 이미 써 본 도구예요

> 📚 **복습 (Chapter06): GaussianBlur**
> `cv2.GaussianBlur`는 각 픽셀 주변 7칸에 가중치 `[0.004, 0.054, 0.242, 0.399, 0.242, 0.054, 0.004]`(0-2 ⑨-3)를 곱해서 더해요. 이것도 **내적**이에요(가중치 수열 · 픽셀 수열). 필터링, 템플릿 매칭, DFT가 모두 "곱해서 더하기"라는 같은 뿌리를 가졌어요.

🚗 **AVM 예시:** 탑뷰 이미지의 한 행에서 **주차선**(밝음-어두움이 일정 간격으로 반복)을 찾고 싶다고 해 볼게요. 그 간격에 맞는 사인파와 그 행을 내적하면, 주차선 간격의 줄무늬가 있을 때만 큰 값이 나와요. 2D DFT(Part 3)는 이 측정을 **모든 간격, 모든 방향**에 대해 한꺼번에 해요. 그래서 스펙트럼을 보면 반복 패턴(타일, 그레이팅)이 **밝은 점**으로 튀어나와요. Part 6에서 모아레 점을 찾는 원리가 이거예요.

## ⑪ 정리 + 셀프 체크

### 한 장 요약
| 개념 | 식 | 의미 |
|---|---|---|
| 내적 | Σ a[n]·b[n] | 닮은 정도 점수 |
| 큰 양수 / 음수 / 0 | | 닮음 / 뒤집힌 닮음 / 무관(직교) |
| 기하학 | \|a\|\|b\| cos(사이각) | 0이면 직각 |
| 같은 사인파끼리 | Σ sin_k · sin_k = N/2 | 측정기 기준값 |
| 다른 주파수끼리 | Σ sin_k · sin_m = 0 | **직교성** → 섞여도 분리 가능 |
| 같은 주파수의 sin과 cos | Σ sin_k · cos_k = 0 | 그래서 측정기 두 개가 필요 |
| 가중치 꺼내기 | (Σ g · sin_k) ÷ (N/2) | 02번의 0.3, −0.7, 0.5 복원 |
| DFT | G[k] = Σ g[n]·e^{−j2πkn/N} | 실수부 = cos 측정, 허수부 = −sin 측정 |

**꼭 가져갈 3문장**
1. **내적 = 같은 자리끼리 곱해서 더하기 = 닮은 정도.** DFT 코드의 `sum(g[n] * exp(...))`가 바로 이거예요.
2. **다른 주파수끼리는 직교(내적 0)라서 측정기 하나는 자기 주파수만 잡아내요.** 그래서 섞인 신호를 분리할 수 있어요.
3. **위상까지 잡으려면 sin과 cos 측정기가 둘 다 필요하고, 그 둘을 합친 게 회전자 e^{−jθ}, 그게 DFT예요.**

### 셀프 체크
1. a = [2, −1, 0, 3], b = [1, 4, 5, −1]의 내적은?
2. N = 8에서 Σ sin2 · sin2는? (⑤-1 표의 sin2 행을 써 보세요)
3. `g = 0.4·sin(2Hz) + 0.9·sin(6Hz)` (N = 16)에 sin 6Hz 측정기를 대면 내적이 얼마일까?
4. 위 g에 sin 4Hz 측정기를 대면?
5. 어떤 신호에 2Hz sin 측정기를 댔더니 0, cos 측정기를 댔더니 −4.8이 나왔어요(N = 16). 이 2Hz 성분의 진폭과 정체는?
6. DFT 결과 G[3] = 0 − 5.6j라면 원래 신호에 들어 있던 3Hz 성분은? (N = 16)

<br>

**정답 ↓**
1. 2·1 + (−1)·4 + 0·5 + 3·(−1) = 2 − 4 + 0 − 3 = **−5**
2. 0² + 1² + 0² + (−1)² + 0² + 1² + 0² + (−1)² = **4** (= N/2)
3. 0.9 × N/2 = 0.9 × 8 = **7.2** (2Hz 성분은 직교라서 0)
4. **0** (4Hz 성분이 없음)
5. 진폭 = √(0² + 4.8²) / 8 = **0.6**. cos 측정값이 음수니까 **−0.6·cos(2Hz)**, 즉 위상이 180°인 코사인이에요.
6. 허수부 = −(sin 측정값)이니까 sin 측정값 = **+5.6** → 5.6 / 8 = **+0.7·sin(3Hz)**
