## 9-3. 함수 치트시트

| 하고 싶은 것 | 코드 | 주의 |
|---|---|---|
| 2D FFT (numpy) | `F = np.fft.fft2(img)` | 결과 complex128 |
| 2D FFT (OpenCV) | `F = cv2.dft(np.float32(img), flags=cv2.DFT_COMPLEX_OUTPUT)` | **float 필수**, 결과 (H, W, 2) |
| 역변환 (numpy) | `np.fft.ifft2(F).real` | 1/N 자동 |
| 역변환 (OpenCV) | `cv2.idft(F, flags=cv2.DFT_SCALE)[:, :, 0]` | **DFT_SCALE 빠지면 H·W배** |
| DC를 가운데로 | `np.fft.fftshift(F)` / `ifftshift` | 수업용 `fftshift`는 홀수 크기에서 한 줄 잃음 |
| 크기 | `np.abs(F)` / `cv2.magnitude(re, im)` | |
| 보기용 스펙트럼 | `cv2.convertScaleAbs(20 * np.log(mag + 1))` | 255에서 포화 |
| 빠른 크기 | `cv2.getOptimalDFTSize(n)` | 2, 3, 5의 곱 |
| 원 마스크 | `cv2.circle(mask, (cx, cy), r, 값, -1)` | 중심 (x, y) 순서, **dft 크기 기준** |
| 밝은 점 마스크 | `cv2.threshold(spec, th, 255, cv2.THRESH_BINARY_INV)[1]` | th는 로그 단위 |
| 마스크로 복사 | `cv2.copyTo(dft, mask=mask)` | 1채널 마스크가 2채널 전체에 적용 |
| 부드러운 마스크 | `cv2.GaussianBlur(mask/255, (0, 0), σ)` 후 곱셈 | 링잉 감소 |
| DCT (OpenCV) | `cv2.dct(f32)`, `cv2.dct(F, flags=cv2.DCT_INVERSE)` | float, 1채널 |
| DCT (scipy) | `scipy.fft.dctn(a, norm='ortho')`, `idctn` | **ortho 필수** |
| JPEG 시험 | `cv2.imencode('.jpg', img, [cv2.IMWRITE_JPEG_QUALITY, q])` | |
| 거울 패딩 | `cv2.copyMakeBorder(img, 0, ph, 0, pw, cv2.BORDER_REFLECT)` | DCT 가정과 같음 |
| 박스 평균 축소 | `cv2.resize(img, size, interpolation=cv2.INTER_AREA)` | = DC Pass |

## 9-4. 공식 모음

```
[샘플링]   df = fs / N            나이퀴스트 = fs / 2          접힘: f_겉보기 = |f − round(f/fs)·fs|
[DFT]      G(k) = Σ g(n) e^(−j2πkn/N)          g(n) = (1/N) Σ G(k) e^(+j2πkn/N)
[진폭]     실수 사인파 진폭 A → |G(k)| = A·N/2 (k와 N−k 두 곳)
[대칭]     실수 신호 → G(N−k) = G(k)* (켤레 대칭) → 마스크도 DC 기준 대칭이어야 결과가 실수
[스펙트럼] 표시값 = 20·ln(|F| + 1)  ⇔  |F| = e^(값/20) − 1
[FFT]      비용 ∝ N·log₂N (직접 DFT는 N²)
[컨볼루션] f ∗ h  ⇔  F · H          가우시안: σ_공간 = N / (2π · σ_주파수)
[필터]     가우시안 H = exp(−D²/2σ²) (D=σ에서 0.607)    버터워스 H = 1/(1 + (D/R)^(2n)) (D=R에서 0.5)
[맥놀이]   두 주파수 f₁, f₂ → 느린 무늬 |f₁ − f₂|      (mo2: |1/3.102 − 1/3| → 91 px)
[DCT]      F(k) = C(k) Σ g(n) cos((n+½)πk/N),  C(0)=√(1/N), C(k)=√(2/N)      8×8: F(0,0) = 8 × 평균
[JPEG]     Fq = round(F / Q)      Q' = floor((Q·s + 50)/100), s = 5000/q (q<50) 또는 200−2q
[PSNR]     10·log₁₀(255² / MSE)
```

## 9-6. 🚗 AVM 핵심 요약

1. **탑뷰 모아레 = 리샘플링 앨리어싱**(0-2). 축소할 때 새 나이퀴스트를 넘는 고주파가 저주파로 접혀요.
2. **접힌 뒤에는 되돌릴 수 없어요**(6-8). mo2 꼭대기에서 진짜 주기 1.78 px가 2.28 px로 둔갑해 진짜 성분 바로 옆에 섞인 것처럼, 스펙트럼에는 "원래 어디서 왔는지" 표시가 없어요. 그래서 **FFT 노치 같은 사후 필터는 주 해법이 될 수 없어요.** HANDOFF의 결정과 같아요.
3. **축소 전에 거르세요**(5-10, 8-9). 이상적 LPF는 링잉(주차선 주변 헤일로)을 만들고, 박스 평균은 sinc 응답이라 고주파가 15~24% 새요. **가우시안·이항 커널**이 둘 다 피해요. 피라미드 한 단에서 0.375 주기/px 성분은 2×2 박스 38.3%, 이항 [1,3,3,1] 5.6%가 통과해요.
4. **주파수 도구가 맞는 자리**(6-8-4): 프리필터 전후 탑뷰 ROI 스펙트럼의 중심 밖 에너지를 비교하는 **진단 지표**, 그리고 위치·시간에 따라 바뀌지 않는 **고정 주파수 잡음**의 노치 제거.
5. **압축이 끼면 조심하세요**(7-10, 8-9-2). 녹화본은 코덱이 고주파 DCT 계수를 이미 깎아서 모아레 평가에 맞지 않아요. 압축 스트림을 워프하면 8×8 블록 격자가 휘어서 블록 현상이 이상한 모양으로 나타나요. **무압축 덤프**로 비교하세요.
6. **"선명함 ↔ 링잉·누설"은 어디서나 맞바꾸기**예요. 이상적 vs 가우시안(5-5), 버터워스 n(5-7), 0/1 vs 부드러운 노치 마스크(6-7-2), 박스 vs 이항(8-9-1) 모두 같은 원리예요.

1. **300 Hz**. 700은 나이퀴스트 500을 넘으니 |700 − 1000| = 300으로 접혀요.
2. df = 1000 / 1000 = **1 Hz**. 0.5 Hz를 구별하려면 df = 0.5 → N = fs / df = **2,000개**(2초)가 필요해요.
3. |G(3)| = A·N/2 = 2 × 1000 / 2 = **1,000**. 켤레 대칭이라 **k = 997**(= −3)에도 1,000이 있어요.
4. 가로 방향 주파수 40이니 **세로 줄무늬**, 주기 240 / 40 = **6픽셀**이에요.
5. **240 × 240 = 57,600배**
6. 원 마스크(절벽)의 공간 커널은 sinc라서 **음수 꼬리**가 있고, 그게 경계 주변에 넘침과 꺼짐을 반복해요. 가우시안의 공간 커널은 다시 가우시안이고 **전부 양수**라서 출렁임이 없어요.
7. σ_s = 256 / (2π × 8) = 256 / 50.27 ≈ **5.09픽셀**
8. e^(220/20) − 1 = e¹¹ − 1 ≈ **59,873**. 원이 없으면 가운데의 DC(255로 포화)와 저주파, X선까지 지워져서 평균 밝기와 큰 구조가 사라지고 **거의 검은 이미지**가 돼요(6-3-4의 장난감처럼).
9. DFT는 **그대로 반복**(`BORDER_WRAP`), DCT는 **거울 반복**(`BORDER_REFLECT`, 가장자리 픽셀 포함)이에요.
10. DCT DC = 8 × (64 − 128) = −512 → −512 / 16 = **−32**
11. 타일: 블록의 상당수가 DC만 남아 **DC Pass 모자이크**가 되고(8-7-6), 블록마다 따로 반올림해서 이웃과 계단이 생겨요(8-6). 모기 잡음: 블록 안의 고주파를 잘라서 생긴 **깁스 출렁임**(5-5, 8-3-4)이에요.
12. ① 앨리어싱은 **비가역**이라 접힌 성분과 진짜 저주파를 구별할 수 없어요. ② 축소율이 **위치마다, 주행 중 프레임마다** 달라서 무늬가 고정된 점으로 모이지 않아요. ③ 주차선 같은 **진짜 내용**까지 지울 위험이 있고, 1080p를 매 프레임 FFT하는 **비용**도 커요.
