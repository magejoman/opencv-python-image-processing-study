# 학습 노트 (Study Notes)

Claude와 챕터별로 진행한 학습 세션을 **원문에 가깝게** 보관하는 폴더입니다.
복습할 때 순서대로 읽고, 각 Part 끝의 확인 질문을 다시 풀어 보세요.

## 폴더 규칙

```
study-notes/
├── README.md                 ← 이 파일 (전체 목차 + 작성 규칙)
└── chapXX/                   ← 챕터마다 폴더 하나 (코드 폴더 이름과 같게)
    ├── README.md             ← 챕터 목차, 다룬 파일, 세션 날짜, 남은 할 일
    ├── 00-plan.md            ← 처음 세운 학습 계획
    ├── 01-<주제>.md           ← Part 1 설명 원문
    ├── 02-<주제>.md           ← Part 2 ...
    └── appendix-<주제>.md     ← 본편 외 질문 (환경 설정, 디버깅 등)
```

- 파일 이름: `두 자리 번호-영문 소문자-하이픈.md` (정렬 순서 = 학습 순서)
- 각 Part 파일 구성: 제목 → 다룬 코드 파일 → (앞 Part 확인 질문 정답) → 본문 → 요약 → 확인 질문
- 코드 링크는 이 폴더 기준 상대 경로 (`../../chap06/02.image_access.py#L21`)
- 실측 숫자는 세션 당시 환경 기준 (아래 표 참고). 버전이 바뀌면 값이 달라질 수 있어요.

## 세션 끝나고 문서화하는 법 (다음 챕터도 동일)

긴 답변을 Claude가 다시 타이핑하면 중간에 잘리거나 표현이 바뀔 수 있어서, **세션 기록(jsonl)에서 답변 원문을 스크립트로 추출**해요.

```
python study-notes/tools/extract_session.py <세션.jsonl> study-notes/chapXX chapXX \
    --slug 1=<주제> --slug 2=<주제> ...
```

- 세션 기록 위치: `C:\Users\<사용자>\.claude\projects\<프로젝트 폴더>\<세션 id>.jsonl`
- 줄 시작이 `# Part N.`(또는 `# 📘 LN.`)인 답변을 `0N-<주제>.md`로 저장하고, 링크를 이 폴더 기준 상대 경로로 바꿔요.
- 제목 앞에 쓴 글(앞 Part 확인 질문 정답)은 제목 바로 아래로 옮겨요.
- Part 0이 있으면 `00-<주제>.md`가 돼요. 주제를 `plan`보다 뒤 글자로 지으면 `00-plan.md` 다음에 정렬돼요.
- `# Part 0-1.`처럼 하위 번호가 붙은 답변은 따로 저장돼요. `--slug 0-1=prereq-1-sine-wave`처럼 하위 번호로 주제를 지정해요 (chap09).
- 같은 Part가 여러 번 나오면 가장 긴 것(최종본)을 써요. Part 하나를 여러 답변에 나눠 설명했다면 `--concat`을 줘서 세션 순서대로 이어 붙여요 (chap07).
- 사람이 직접 쓰는 파일(`README.md`, `00-plan.md`, `appendix-*.md`)은 스크립트가 건드리지 않아요.
- 저장 후 각 파일의 첫 줄과 마지막 줄을 확인해서 잘린 곳이 없는지 봐요.
