## 0. Chapter 12는 어떤 장인가?

Chapter 12는 새 함수 하나를 배우는 장이 아닙니다. **지금까지 나온 영상처리 기술을 조립해서 실제 문제 두 개를 푸는 "응용 프로젝트" 장**이에요.

> 🍕 비유: 블러, 이진화, 윤곽선, 히스토그램, 회전, 머신러닝 같은 레고 부품으로 완성품 두 개를 만든다고 보면 됩니다.

```
[프로젝트 A] 동전 사진 ──▶ "Total coin: 3,160 Won"
  사진 → 흑백 → 이진화 → 동전 윤곽 → 원 검출 → 동전 오려내기
       → 색상 히스토그램 → 구리색/은색 그룹 → 반지름+그룹으로 종류 판정 → 합계

[프로젝트 B] 자동차 사진 ──▶ "12 가 3456"
  사진 → 세로 에지 → 덩어리 만들기 → 번호판 후보 사각형
       → floodFill로 다듬기 → 기울기 펴서 오려내기 → SVM: "진짜 번호판?"
       → 글자 7개 분리 → k-NN: "이 글자는 3, 이 글자는 가" → 문자열
```

### PART A. 동전 인식 (01 → 02 → 03)

**Step 1. 전처리: 동전을 흰 덩어리로 만들기** ([coin_preprocess.py](header/coin_preprocess.py))
- **1-1** 컬러 → 흑백: 색을 왜 버리는가? (모양만 필요하니까)
- **1-2** 📚 GaussianBlur(7×7, σ=2) 복습: 이진화 **전에** 블러하는 이유 (노이즈가 깨알 점으로 남는 문제)
- **1-3** 🧱 이진화: 픽셀마다 실행되는 if문 하나. 5×5 숫자 격자 before/after
- **1-4** 🧱 Otsu 자동 임계값: 🧮 σ²_B = w₀·w₁·(μ₀−μ₁)²
  - 8단계짜리 장난감 히스토그램으로 **모든 t에 대해 손계산 표** 작성
  - ⚠️ OTSU 플래그를 쓰면 코드의 `130`은 사실상 무시된다는 점 → 70번 사진에서 실제 Otsu 값 출력
- **1-5** 🧱 모폴로지 열림(침식 → 팽창): 🍕 "모래알 지우개". 7×7 격자로 한 단계씩
- **1-6** 🔢 실제 70번 사진의 단계별 중간 결과

**Step 2. 동전 찾기** ([01.find_coins.py](01.find_coins.py), `find_coins`)
- **2-1** 🧱 findContours: 흰 덩어리의 테두리 좌표 목록. `RETR_EXTERNAL`, `CHAIN_APPROX_SIMPLE`을 격자 그림으로
- **2-2** OpenCV 버전마다 반환값이 다른 문제 (`results[0]` vs `results[1]`)
- **2-3** 🧱 minEnclosingCircle: 점들을 전부 감싸는 가장 작은 원
- **2-4** `radius>25` 필터. 리스트 컴프리헨션 2단계를 주석 처리된 for문 버전과 1:1로 비교
- **2-5** 🔢 결과 해석: 원 20개, 반지름 분포 44~53

**Step 3. 동전을 하나씩 오려내기** ([coin_utils.py](header/coin_utils.py) `make_coin_img`)
- **3-1** getRectSubPix: 중심 기준으로 (반지름×3) 크기 정사각형 잘라내기
- **3-2** 원형 마스크 만들기 (검은 판 위에 흰 원)
- **3-3** 📚 inRange 마스크 복습 → bitwise_and를 비트 단위로 계산 (200 & 255 = 200, 200 & 0 = 0)
- **3-4** ⚠️ 마스크 바깥이 검정(0)이 된다는 점. Step 4의 복선입니다

**Step 4. 색 분포 재기: Hue 히스토그램** ([02.draw_coin_histo.py](02.draw_coin_histo.py), `calc_histo_hue`)
- **4-1** 📚 HSV 복습: OpenCV의 Hue는 0~179 (360°를 반으로 줄인 값). 색상환 그림
- **4-2** 🧱 히스토그램: 🍕 "투표함 32개". 칸 하나의 폭은 180/32 = 5.625
- **4-3** calcHist 인자 5개 해부
- **4-4** 🔢 실제 동전 하나의 32칸 숫자를 전부 출력하고 ASCII 막대그래프로 그리기
- **4-5** ⚠️ 검정 배경 픽셀(H=0)이 0번 칸에 몰리는 현상을 실제 수치로 확인
- **4-6** `draw_histo_hue`가 그림을 그리는 방식과 02번 결과 화면 읽는 법

**Step 5. 구리색 vs 은색 그룹 나누기** (`grouping`)
- **5-1** 반지름만으로는 왜 부족한가: 실제 반지름 표로 확인
- **5-2** 가중치 벡터 `ws` 해부: 13~25번 칸에만 값이 있고 19번이 8로 최대. 이 칸들이 **어떤 색**인지 Hue로 계산
- **5-3** 🧮 점수 s = Σ(hᵢ·wᵢ) / Σhᵢ: 🍕 "과목별 가중치를 준 성적표". `np.multiply`와 `sum(axis=1)`의 중간 배열 모양까지
- **5-4** 🔢 동전 20개의 s 값 표와 1.2 기준 판정 결과
- **5-5** 한계: 조명이 바뀌면? 임계값이 고정이라면?

**Step 6. 반지름 + 그룹 → 동전 종류** (`classify_coins`)
- **6-1** 2×70 룩업 테이블 `g`를 표로 직접 그려보기
- **6-2** 실제 한국 동전 지름(10원, 50원, 100원, 500원)과 픽셀 반지름 구간을 대응시키기
- **6-3** 🔢 동전 20개를 `g[group, radius]`로 하나씩 추적하는 표
- **6-4** ⚠️ 숨은 버그: 테이블 값이 −1인 반지름(26 미만)이면 `ncoins[-1]`이 되어 **500원으로 잘못 세집니다.** 반지름이 70 이상이면 IndexError가 납니다

**Step 7. 금액 계산 & 시각화** ([03.calc_coins.py](03.calc_coins.py))
- **7-1** `coin_value * ncoins` 벡터 곱의 합
- **7-2** put_string으로 글자 쓰기, 그룹별 색깔 원 그리기
- **7-3** 프로젝트 A 전체 다이어그램과 단계별 중간 결과 한 줄 요약
- **7-4** ✍️ 확인 문제

### PART B. 번호판 인식 (05 → 06 → 04 → 07 → 08)

**Step 8. 번호판 후보 전처리** ([plate_preprocess.py](header/plate_preprocess.py) `preprocessing`)
- **8-1** 번호판 관찰: "흰 바탕에 검은 글자가 가로로 촘촘하다" → 세로 경계선이 빽빽하다
- **8-2** 📚 blur(평균 필터)와 GaussianBlur의 차이
- **8-3** 🧱 Sobel: 미분 = "옆 픽셀과의 차이". 3×3 커널을 장난감 5×5 이미지에 **직접 컨볼루션 계산**. `dx=1, dy=0`이 세로 경계를 잡는 이유
- **8-4** ⚠️ `CV_8U`의 함정: 음수가 0으로 잘려서 한쪽 방향 경계가 사라짐 (수치 예시)
- **8-5** ⚠️ 위치 인자 함정: `Sobel(gray, CV_8U, 1, 0, 3)`에서 `3`은 ksize가 아니라 dst 자리에 들어갑니다
- **8-6** 🧱 닫힘 연산(팽창 → 침식): 커널이 **5×13으로 가로로 긴 이유**와 `iterations=3`을 격자 그림으로
- **8-7** 🔢 0번 자동차의 단계별 중간 결과

**Step 9. 후보 영역 찾기** ([05.find_plates.py](05.find_plates.py), `find_candidates`)
- **9-1** 📚 findContours (Step 2 복습)
- **9-2** 🧱 minAreaRect: 회전된 최소 사각형 `((cx,cy),(w,h),angle)`. 각도 규칙은 버전마다 다르니 실제 출력으로 확인
- **9-3** boxPoints로 꼭짓점 4개를 구하고 polylines로 그리기
- **9-4** `verify_aspect_size`: 넓이 3000~12000, 종횡비 2.0~6.5. 실제 번호판 비율과 비교
- **9-5** 🔢 0번 자동차의 후보 3개 수치 표

**Step 10. 후보 다듬기 ①: floodFill** ([plate_candidate.py](header/plate_candidate.py) `color_candidate_img`)
- **10-1** 다듬기가 왜 필요한가: 닫힘 결과의 경계가 부정확하다
- **10-2** 🧱 floodFill: 🍕 그림판 페인트통. 4-연결 vs 8-연결 격자 예시
- **10-3** FIXED_RANGE: 시작점 색 기준 ±25
- **10-4** 🧮 `flags = 4 + 0xff00 + FIXED_RANGE + MASK_ONLY`를 **이진수 비트로 펼쳐서** 해부
- **10-5** 마스크 크기가 (h+2, w+2)인 이유
- **10-6** 랜덤 시드 20개(중심 ±15px)를 쓰는 이유: 시드가 글자 위에 찍힐 수도 있어서
- **10-7** 🔢 다시 find_candidates를 돌렸을 때 사각형이 어떻게 바뀌는지 before/after

**Step 11. 후보 다듬기 ②: 기울기 펴고 오려내기** ([06.correct_plate.py](06.correct_plate.py), `rotate_plate`)
- **11-1** `w<h`이면 가로·세로를 바꾸고 각도에 +90을 하는 이유
- **11-2** 🧱 🧮 2×3 회전 행렬: 중심 기준 회전 = 이동 → 회전 → 되돌리기. 실제 숫자를 넣어 점 하나의 이동을 손계산
- **11-3** 📚 호모그래피(3×3)와 연결: affine은 호모그래피의 특수한 경우
- **11-4** warpAffine과 보간 개념. ⚠️ `INTER_CUBIC`이 정말 flags 자리에 들어가는지 확인 (8-5와 같은 함정)
- **11-5** 144×28로 크기를 고정하는 이유: SVM 입력 길이가 같아야 하기 때문
- **11-6** 🔢 06번 실행 결과 영상들

**Step 12. 🧱 머신러닝 기초** (큰 블록)
- **12-1** 규칙 기반 vs 학습 기반: "번호판이란 무엇인가"를 if문으로 쓰기 어려운 이유
- **12-2** 특징 벡터: 28×144 이미지를 4032개 숫자 한 줄로 펴기 (reshape 그림)
- **12-3** 학습 데이터 + 라벨(1/0). 학습 단계 → 예측 단계

**Step 13. SVM 원리**
- **13-1** 2D 점 예시: 두 그룹을 가르는 직선
- **13-2** 마진과 서포트 벡터: 🍕 "두 동네 사이 도로를 최대한 넓게 깔기"
- **13-3** 🧮 w·x + b의 부호로 판정. 4032차원에서도 원리는 같음 (초평면)
- **13-4** C 파라미터(소프트 마진), 커널(선형 vs RBF). ⚠️ LINEAR 커널에서는 `setGamma`가 의미 없음
- **13-5** 🔢 장난감 데이터로 SVM을 직접 학습시켜 w, b, 서포트 벡터 출력

**Step 14. SVM 학습 코드** ([04.train_plate_data.py](04.train_plate_data.py))

- **15-3** 🔢 자동차 여러 장의 성공/실패 표 (초록 = 번호판, 빨강 = 아님)

**Step 16. k-NN 원리**
- **16-1** 🍕 "나랑 가장 비슷한 친구 K명에게 물어보고 다수결"
- **16-2** 🧮 유클리드 거리: 2D 손계산 → 1600차원으로 확장
- **16-3** K의 역할 (K=1 vs K=10)
- **16-4** SVM과 비교: k-NN은 학습 = 그냥 저장해 두기 (lazy learning)

**Step 17. k-NN 학습 데이터 만들기** ([plate_classify.py](header/plate_classify.py) `kNN_train` + [Common/knn.py](../Common/knn.py))
- **17-1** 학습 이미지 격자 구조 (숫자 10행×20열, 한글 40행×20열)
- **17-2** 🔢 여백 제거 계산: 411 % 40 = 11 → dy = 5 … 실제 숫자 대입
- **17-3** vsplit/hsplit로 셀 나누기 그림
- **17-4** 🧱 투영(projection), `find_number`: 행·열 평균을 내서 글자가 있는 범위 찾기
- **17-5** `place_middle`: 정사각형 중앙에 배치 → 40×40 → 1600 벡터 (위치와 크기 정규화)

**Step 18. 번호판에서 글자 7개 찾기** (`preprocessing_plate`, `find_objects`)
- **18-1** 180×35로 리사이즈 → Otsu 이진화 → 여백 깎기

- **18-3** 🧱 boundingRect와 필터 (w/h < 2.5, 넓이)
- **18-4** 한글은 자모가 떨어져 여러 조각이 됨 → x ∈ (45, 80) 조각을 하나로 합치기. `np.sort(axis=0)`가 **열마다 따로 정렬**하는 트릭
- **18-5** 🔢 실제 번호판에서 찾은 ROI 목록

**Step 19. 글자 분류 & 최종 결과** ([08.classify_number.py](08.classify_number.py), `classify_numbers`)
- **19-1** 글자가 7개인지 검사 (구형 번호판 "12가3456" 형식)
