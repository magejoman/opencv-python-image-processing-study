## 🎨 Part A. PaintCV

### Step 1. 도화지와 아이콘 메뉴 배치 ([01.place_icons.py](../../chap11/01.place_icons.py), `place_icons`)
- 1-1. 📚 좌표계 복습: numpy는 `[행, 열] = [y, x]`, OpenCV 함수는 `(x, y)`
- 1-2. 🔢 `(i%2, i//2, 1, 1)` 공식: i = 0~11 각각이 몇 번째 격자 칸이 되는지 12줄 표로 정리
- 1-3. ⚠️ `size*2`의 함정: `(60,60)*2`는 120이 아니라 **`(60,60,60,60)`** (튜플 반복). 여기에 numpy 브로드캐스팅이 더해져 픽셀 사각형 12개가 나옵니다. 그 12개를 표로 보여줍니다.
- 1-4. ROI 슬라이싱으로 아이콘 붙이기: `image[y:y+h, x:x+w] = resize(...)`
- 1-5. 🖼️ 결과 화면 지도: 2열×6행, 120×360 픽셀 메뉴판

### Step 2. 색 고르기 UI: HSV 색상 바와 팔레트 ([02.place_menu.py](../../chap11/02.place_menu.py), `create_hueIndex`, `create_colorPlatte`)
- 2-1. 🆕🧠 HSV 미니 강의: H = 어떤 물감, S = 물감 진하기, V = 조명 밝기. OpenCV의 H가 0~179인 이유(360은 uint8에 안 들어가서 절반으로 줄임)
- 2-2. 🔢 ROI 좌표 계산: 마지막 아이콘 `(60,300,60,60)`에서 팔레트 `(0,362,120,120)`, 색상 바 `(0,484,120,15)`가 나오는 과정
- 2-3. 🔢 `create_hueIndex`: 리스트 컴프리헨션이 (15,120,3) 배열이 되고, `×(1.5, 255, 255)`를 곱하고, `astype` 버림을 거쳐 HSV→BGR로 바뀌는 과정. j = 0, 1, 2, …, 119의 중간값 표 포함
- 2-4. 🔢 `create_colorPlatte`: 가로축은 채도, 세로축은 명도. `h-i-1`로 위아래를 뒤집는 이유. 네 모서리 픽셀의 HSV/BGR 값을 직접 계산
- 2-5. 설계 트릭: icons 리스트의 인덱스가 곧 명령 번호입니다([paint_init.py](../../chap11/header/paint_init.py)의 상수 0~13)
- 2-6. (보너스) 안 쓰이는 `create_colorPlatte1/2`는 무엇이 다른지

### Step 3. 마우스로 메뉴 클릭 처리 ([03.event_platte.py](../../chap11/03.event_platte.py))
- 3-1. 📚 `setMouseCallback` 복습. 🧠 콜백은 "내가 부르는 함수"가 아니라 "초인종이 울리면 OpenCV가 대신 부르는 함수"
- 3-2. 🔢 클릭 판정(hit-test): 14개 사각형을 순서대로 검사. `x0 <= x < x0+w`처럼 반만 열린 구간을 쓰는 이유. (75,130)을 클릭했을 때 어떻게 판정되는지 추적
- 3-3. 분기: 그리기 명령(i<6)과 일반 명령(i≥6)
- 3-4. 🔢 `image[pt2[::-1]]` 트릭: (x,y)를 (y,x)로 뒤집어 픽셀을 꺼냅니다. `tuple(map(int, pixel))`이 꼭 필요한 이유
- 3-5. 🔢 색상 바 클릭: x=60을 누르면 hue=60, ×1.5 하면 90, 팔레트 전체가 다시 그려지는 과정
- 3-6. `global` 패턴: 콜백이 상태를 바꾸려면 왜 global이 필요한가

### Step 4. 마우스 상태 기계와 도형 그리기 ([04.draw_command.py](../../chap11/04.draw_command.py)) ⭐ Part A의 핵심
- 4-1. 🆕🖼️ 상태 기계: `mouse_mode` 0/1/2/3 사이의 상태 전이 다이어그램
- 4-2. 🧠 분업 구조: 콜백(웨이터)은 주문서만 쓰고, `while` 루프(주방)가 30ms마다 요리합니다
- 4-3. `x < 125` 가드: 메뉴 위에서 드래그하면 무시
- 4-4. 🔢 **시간축 추적표**: (200,100)에서 누르고, (250,140)으로 끌고, (300,180)에서 뗄 때 프레임마다 `mouse_mode`, `pt1`, `pt2`, 화면에 그려지는 것
- 4-5. 러버밴드 미리보기: `np.copy(image)`에 회색으로 그려 보여주고 버리는 이유
- 4-6. 📐 도형별 수학
  - 원: 피타고라스로 반지름 계산
  - 타원: 중점 `(p1+p2)//2`, 반축 `|p1−p2|//2`
  - 브러시: 짧은 선분을 이어 붙이고 `pt1 = pt2`로 갱신 (적분과 같은 원리)
- 4-7. 🔍 관찰 포인트: 마우스를 뗀 뒤에도 `mouse_mode==1`이 유지되어 30ms마다 같은 도형을 다시 그립니다. 같은 걸 덮어 그리니 눈에는 안 보이지만, Step 5의 두 줄이 존재하는 이유가 됩니다.

### Step 5. 완성판: 열기/저장/밝기/지우기와 트랙바 ([05.PaintCV.py](../../chap11/05.PaintCV.py))

### Step 8. Haar Cascade 얼굴 검출의 원리 (Viola–Jones, 2001) ⭐⭐ 챕터 전체의 핵심 이론, 가장 길게
- 8-1. 🧠 큰 그림: 공항 보안 검색대가 여러 겹 있다고 생각하면 됩니다. 후보 창 대부분은 첫 게이트에서 탈락합니다
- 8-2. 🔢 Haar-like 특징 = 흰 영역의 합 − 검은 영역의 합. "눈은 볼보다 어둡다", "콧대는 양옆보다 밝다"를 6×6 숫자 패치로 직접 계산
- 8-3. 📐🔢 적분 영상: 어떤 사각형의 합이든 덧셈·뺄셈 4번으로 구합니다. 5×5 예제로 적분 영상 표를 만들고 검증
- 8-4. 📐 약한 분류기(문턱값 하나짜리 판정)와 AdaBoost 가중 투표
- 8-5. 🔢 **실제 `haarcascade_frontalface_alt2.xml` 해부**: 몇 단계(stage)인지, 단계마다 약한 분류기가 몇 개인지, 특징 하나가 실제 숫자로 어떻게 생겼는지
- 8-6. 🔢 슬라이딩 윈도우와 이미지 피라미드: 34.jpg(500×349)에서 scaleFactor 1.1로 몇 단계를 도는지, 단계별 창 크기 표
- 8-7. 🖼️ `minNeighbors`: 한 얼굴 주위에 겹쳐 나온 후보 사각형들을 하나로 묶는 원리
- 8-8. `detectMultiScale(gray, 1.1, 2, 0, (100,100))` 인자를 하나씩 해부하고, 실측 결과 `[174,71,158,158]`과 연결
- 8-9. 📚 비교표: Chapter06의 MediaPipe(딥러닝)와 Haar(고전 기법)
