로버츠가 잡음에 약한 이유 — 두 실험을 직접 돌려 보기

핵심 사실 하나: 로버츠 출력 한 픽셀 = 정확히 2개 입력 픽셀의 차이(가중치 +1, −1). 평균화가 없어서 잡음이 그대로 통과합니다.

모든 수치는 Common/filters.py의 filter() + cv2.magnitude와 동일한 연산으로 검증되었습니다.

실험 ① — 잡음 점 하나가 만드는 가짜 에지

전부 100인 평평한 영상의 가운데 (2,2)만 100 + Δ로 바꿉니다. 잡음 점이 영향을 주는 출력은 정확히 3곳뿐입니다 (자기 자리에서 두 마스크의 중심으로 2번, 아래행 양쪽 대각에서 −1 이웃으로 1번씩). Δ 슬라이더를 움직여 보세요.

잡음 크기 Δ = 30     |   진짜 에지 대비 C = 80  

실험 ② — 화면 전체 가우시안 잡음: 왜 표준편차가 σ√2 인가

모든 픽셀이 독립 일 때, 은 독립인 두 가우시안의 차이이므로

아래 히스토그램은 400×400 잡음 영상(158,404개 유효 픽셀)의 G₁ 실측 분포이고, 곡선은 이론 입니다. 임계값 T 슬라이더를 움직이면 |G₁| > T 인 가짜 에지 픽셀 수(실측 vs 이론)를 볼 수 있습니다. 파란 세로선은 진짜 에지 반응(대비 80)의 위치입니다.

σ = 10        |   임계값 T = 40  

비교 — 평균화가 있는 소벨은 왜 나은가

일반 원리: 독립 잡음 N개를 합하면 신호는 N배(같은 방향으로 더해짐), 잡음 표준편차는 √N배(분산이 더해짐) → SNR은 √N배 개선. 소벨 Gx = [1 0 −1; 2 0 −2; 1 0 −1]은 에지를 따라 3픽셀을 (1,2,1)로 가중 평균한 뒤 차분합니다.

신호 이득 (대비 C 에지)잡음 이득 (표준편차)SNR (C=80, σ=10)최소 검출 대비 (3σ 기준)
로버츠 (2픽셀 차분)1 × C = 80σ√2 = 14.1480 / 14.14 = 5.663 × 14.14 ≈ 42.4
소벨 (3픽셀 가중평균 후 차분)4 × C = 320σ√12 = 34.64320 / 34.64 = 9.243 × 34.64 / 4 ≈ 26.0

소벨의 잡음 표준편차가 더 크게 나오는 것(34.6 > 14.1)이 함정입니다 — 6개 픽셀을 더하니까요. 하지만 신호가 4배로 더 크게 불어나므로 비율(SNR)로 보면 소벨이 1.63배 좋고, 같은 잡음에서 더 약한 에지(대비 26~42)까지 구분할 수 있습니다.
