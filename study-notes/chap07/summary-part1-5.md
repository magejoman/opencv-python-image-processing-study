# chap07 핵심 요약: Part 1 ~ 5 (회선, 에지, 잡음 제거, LoG/DoG)

> 복습용 압축본이에요. 자세한 손계산과 실험은 Part 파일(01 ~ 05)에 있어요.
> 숫자는 세션에서 실제로 돌린 값이에요 (NumPy 2.1.2, OpenCV 4.12.0).

## 한 장 요약

```
화소 처리 (chap06)  : 출력 = f(입력 화소 하나)
영역 처리 (chap07)  : 출력 = f(입력 화소 + 이웃)
   ├─ 선형   : 이웃 × 가중치(마스크)의 합  → 블러, 샤프닝, 미분(에지)
   └─ 비선형 : 이웃을 정렬해서 하나 고르기 → 미디언, 최소, 최대

에지 검출 흐름:  잡음 제거(가우시안) → 미분(1차: 소벨 / 2차: 라플라시안) → 위치 찾기
```

**가장 중요한 규칙 세 개**

1. **마스크 원소의 합** = 평평한 곳의 결과 배율. 합 1 → 밝기 유지 (블러, 샤프닝), 합 0 → 에지만 남음 (미분).
2. **음수가 나오는 계산은 음수를 담는 자료형으로** (`float32`, `CV_16S`, `CV_32F`). uint8이면 한 바퀴 돌거나(numpy) 0으로 잘림(OpenCV).
3. **OpenCV의 숫자 옵션은 항상 키워드로.** `Sobel(…, 3)`, `Laplacian(…, 1)`, `GaussianBlur(…, 10.7, 1.3)`, `phase(…, True)`의 마지막 값은 전부 `dst` 자리라 무시돼요.

## Part 1. 회선 (Convolution) — [01](../../chap07/01.blurring.py), [02](../../chap07/02.sharpening.py)

**회선 = 마스크를 겹쳐서 원소끼리 곱하고 전부 더하기, 모든 위치에서 반복.**

```
dst(i, j) = Σ_u Σ_v  src(i + u − c, j + v − c) · mask(u, v)        c = 마스크 크기 // 2
```

| 핵심 | 내용 |
|---|---|
| 왜 이웃? | 가운데 값이 같아도(255) 이웃에 따라 잡음인지 물체인지 다름 (평균 37 vs 173) |
| 출력은 새 배열에 | 원본에 덮어쓰면 다음 창이 이미 바뀐 값을 읽음 (46.67 → 37.78) |
| 테두리 | 책 코드는 0 (검은 액자). OpenCV 기본은 `REFLECT_101` (`4 3 2 \| 1 2 3 4 5 \| 4 3 2`) |
| 상관 vs 회선 | `filter2D`는 마스크를 **뒤집지 않음**(상관). 비대칭 마스크에서만 부호 차이 |
| 평균 블러 | 1/9 × 9. 잡음은 줄고 퍼지며, 계단은 경사로가 됨 |
| 샤프닝 | `δ + k(δ − 평균)`, k = 4 → `[0 −1 0 / −1 5 −1 / 0 −1 0]` = **원본 − 라플라시안** |

**코드에서 기억할 것**
- 직접 만든 `filter()`: 슬라이싱 → `astype(float32)` → `cv2.multiply`(원소끼리, 행렬 곱 아님) → `cv2.sumElems(...)[0]`(4채널 튜플)
- `astype("uint8")`은 **버림**, `convertScaleAbs`는 **반올림 + 절댓값 + 포화** (.5는 짝수 쪽: 127.5 → 128)
- 속도: 직접 만든 함수 0.23 s vs `cv2.filter2D` 0.1 ms → 직접 만든 건 학습용

**⚠️ 함정**
- 01: "blur2" 창에 `blur1` 표시 ([L49](../../chap07/01.blurring.py#L49))
- 02: 샤프닝 결과에 `convertScaleAbs` → 음수(어두운 쪽)가 밝게 뒤집힘 (20 → 251). **clip 하거나 `filter2D(img, -1, mask)`** 써야 함

## Part 2. 1차 미분 에지 — [03](../../chap07/03.edge_roberts.py), [04](../../chap07/04.edge_prewitt.py), [05](../../chap07/05.edge_sobel.py)

**에지 = 밝기가 짧은 거리에서 크게 변하는 곳 = 미분값이 큰 곳.**

```
중앙 차분:  f'(x) ≈ f(x+1) − f(x−1)          마스크 [−1, 0, 1]  (÷2 생략, 원소 합 0)
그래디언트: (Gx, Gy),  크기 √(Gx² + Gy²),  방향 atan2(Gy, Gx)
```

| 핵심 | 내용 |
|---|---|
| 부호 | + = 밝아짐, − = 어두워짐. 선은 `+, 0, −` 쌍 (가운데 0) |
| 방향 | 그래디언트는 **에지와 수직**, 밝은 쪽을 가리킴. y가 아래로 커져서 각도는 시계 방향 |
| 크기 근사 | `|Gx| + |Gy|`는 대각선에서 최대 1.414배 과대 |
| `cv2.magnitude`, `cv2.phase` | float32/64, 같은 자료형만. `phase`는 0 ~ 360° |

| 연산자 | 마스크 (Gx) | 구조 | SNR (σ=10) | 특징 |
|---|---|---|---|---|
| 로버츠 | 대각선 2화소 차분 | — | 5.65 | 반 칸 어긋남, 잡음에 약함 |
| 프리윗 | `[1,1,1]ᵀ × [−1,0,1]` | 평균 + 미분 | **9.80** | "수직 마스크" = Gx = **세로 에지** 검출 |
| 소벨 | `[1,2,1]ᵀ × [−1,0,1]` | 가우시안 근사 + 미분 | 9.24 | **방향 오차가 절반** (1.35° vs 2.89°) → 표준 |

**⚠️ 함정**
- `cv2.Sobel(img, CV_32F, 1, 0, 3)`의 3은 `dst` 자리 (5를 넣어도 3×3). → `ksize=3`
- `ddepth=CV_8U`면 음수 에지가 사라짐 (−215 → 0). 주차선처럼 **부호 쌍**이 필요하면 `CV_16S` / `CV_32F`
- 화면 밝기 차이는 대부분 배율 (로버츠 : 프리윗 : 소벨 = 1 : 3 : 4)

## Part 3. 2차 미분, 라플라시안 — [06](../../chap07/06.edge_laplacian.py)

**2차 미분 = 기울기의 기울기. 에지 위치 = 영교차(+ → −로 바뀌는 곳).**

```
1D:  f''(x) ≈ f(x+1) − 2f(x) + f(x−1)          [1, −2, 1]
2D:  ∇²f = ∂²f/∂x² + ∂²f/∂y²                    [0 1 0 / 1 −4 1 / 0 1 0]   (8방향: [1 1 1 / 1 −8 1 / 1 1 1])
```

| 핵심 | 내용 |
|---|---|
| 1차 vs 2차 | 1차의 꼭대기 = 2차의 영교차 (위치, 속도, 가속도 비유) |
| 선 | 선 한가운데에 강하게 반응 (흰 선 −380), 일정한 경사는 0 |
| 마스크 하나 | 방향 무관, 대신 방향 정보 없음 |
| 샤프닝 | `δ − 라플라시안` = Part 1의 샤프닝 마스크 |
| 잡음 | 잡음 점 하나가 진짜 에지보다 셈 (150%), SNR 1.78 (소벨 9.24) |
| 화질 지표 | 라플라시안 분산 = 선명도 (원본 1183 → σ1 블러 44.5). 초점, 렌즈 오염 검사 |

**⚠️ 함정**
- 06의 8방향 마스크(`−1…8…−1`)는 4방향과 **부호가 반대**
- `cv2.Laplacian(img, CV_16S, 1)`의 1은 `dst` 자리. 기본 ksize=1이라 우연히 맞음. ksize=3은 `[2 0 2 / 0 −8 0 / 2 0 2]`
- `convertScaleAbs`로 띄우면 영교차가 사라져서 **이중선**으로 보임

## Part 4. 잡음 제거 필터 — [10](../../chap07/10.filter_average.py), [12](../../chap07/12.filter_gaussian.py), [11](../../chap07/11.filter_median.py), [09](../../chap07/09.filter_minmax.py)

| 잡음 | 모양 | 원인 |
|---|---|---|
| 가우시안 | **모든** 화소가 ±σ 흔들림 | 센서 열, 저조도 (밤 영상) |
| 소금-후추 | **일부** 화소가 0 / 255, 원래 값 사라짐 | 전송 오류, 죽은 화소 |

| 필터 | 원리 | 기억할 숫자 / 성질 |
|---|---|---|
| **평균** | 모두 같은 가중치 | 가우시안 잡음 σ → **σ ÷ k**. 소금은 **얼룩으로 퍼짐**. `cv2.blur`는 슬라이딩 합이라 크기 무관 |
| **가우시안** | 가까울수록 큰 가중치 `exp(−x²/2σ²)` | σ가 흐림 세기. 마스크 크기 ≈ 6σ + 1. 분리 가능 (k² → 2k). 같은 크기면 평균보다 **에지를 덜 흐림** |
| **미디언** | 정렬해서 가운데 | 소금-후추 최강 (494점 중 10점만 남음). 에지 보존. **창 절반보다 가는 선은 지움**, 잡음이 절반 넘으면 실패 |
| **최소 / 최대** | 정렬의 맨 앞 / 맨 뒤 | 최소 = 소금 제거 + 어두운 것 확대 = `erode`, 최대 = 반대 = `dilate` (Part 7) |

**가우시안 공식 요약**
- σ 자동 계산: `σ = 0.3((k − 1)·0.5 − 1) + 0.8` (k=3 → 0.8, 5 → 1.1, 17 → 2.9)
- k ≤ 7, σ ≤ 0이면 OpenCV는 이항 표 사용: `[1,2,1]/4`, `[1,4,6,4,1]/16` (소벨의 `[1,2,1]`과 같은 것)
- 2D = 1D × 1D (`meshgrid` → 거리² → exp → **합으로 나눠 정규화**)

**선택 기준:** 가우시안 잡음 → 가우시안(에지 보존) 또는 평균(잡음 최소). 소금-후추 → 미디언. 둘 다 있으면 **미디언 먼저, 가우시안 나중**.

**⚠️ 함정**
- 10: "blur_img" 창에 `box_img` 표시 ([L28](../../chap07/10.filter_average.py#L28)), uint8 저장 시 소수 버림
- 12: `np.arange(0, ksize+1)` → **18×6 마스크**, 결과가 (1, 1)화소 밀림 ([L8-9](../../chap07/12.filter_gaussian.py#L8-L9))
- 12: `GaussianBlur(image, (0,0), 10.7, 1.3)`의 1.3은 `dst` 자리 → sigmaY도 10.7, 완전히 뭉개짐 ([L26](../../chap07/12.filter_gaussian.py#L26))
- 11: 1D 배열을 `cv2.sort`에 넘기면 9×1 세로 행렬 → `SORT_EVERY_COLUMN`이어야 정렬됨
- `cv2.minMaxLoc`의 위치는 `(x, y)` 순서

## Part 5. LoG와 DoG — [07](../../chap07/07.edge_DOG.py)

**LoG = 가우시안으로 흐린 뒤 라플라시안. 회선의 결합 법칙으로 마스크 하나(멕시칸 햇).**

```
L * (G * f) = (L * G) * f                  9×9 가우시안 + 3×3 라플라시안 → 11×11 LoG
LoG(x) ∝ (x² − σ²)/σ⁴ · exp(−x²/2σ²)       영교차 x = ±σ → σ가 반응할 구조의 크기
DoG = G(σ₁) * f − G(σ₂) * f  ≈  −LoG        σ 비율 약 1.6이면 상관계수 0.994
```

| 핵심 | 내용 |
|---|---|
| SNR 개선 | 라플라시안만 1.78 → 가우시안 9×9 후 **8.51** |
| 위치 | 영교차는 여전히 정확한 경계 위치, 1화소 두께 에지 |
| DoG = 대역 통과 | 가는 잡음과 굵은 조명은 버리고 중간 굵기(에지)만 남김 (4 ~ 8화소 줄무늬 23 남음, 64화소 0.5) |
| DoG를 쓰는 이유 | 가우시안은 빠르고(분리 가능), 여러 σ를 빼기만 하면 여러 크기의 LoG (SIFT) |

**⚠️ 함정 (07번 세 개)**
- `cv2.Laplacian(gaus, CV_16S, 9)`의 9는 `dst` 자리 → 3×3 (진짜 ksize=9면 int16 포화)
- `dst1.astype("uint8")` → −30이 226 (음수 41.9%가 흰색)
- `gaus1 − gaus2` (uint8) → 10 − 20이 246. **빼기 전에 `astype(np.int16)`**
- 표시: `convertScaleAbs`(세기만), `×k + 128`(부호 표시), `cv2.normalize`(범위 늘리기)

## 🚗 AVM과 연결되는 포인트

| 주제 | 포인트 |
|---|---|
| 모아레 | 톱뷰 축소 **전에** 블러(가우시안) = 안티에일리어싱 |
| 샤프닝 | ISP가 이미 샤프닝 → 중복 시 잡음, 리샘플링 자국, 주차선 후광 증폭 |
| 주차선 검출 | 소벨 x를 `CV_16S`/`CV_32F`로 → `+에지 … −에지` 쌍 찾기. 선 폭에 맞춘 DoG |
| 필터 크기 | 먼 곳 주차선은 1 ~ 2화소 → 큰 미디언/평균은 선을 지움 |
| 밤 영상 | 가우시안 잡음 ↑. 평균은 σ ÷ k로 줄이지만 선도 흐림 |
| 화질 검사 | 라플라시안 분산으로 초점 이탈, 렌즈 오염, 안개 판단 (같은 조건끼리 비교) |
| 실시간 | 분리 가능 필터(가로 → 세로 두 패스), `cv2.*` 함수 사용 |
