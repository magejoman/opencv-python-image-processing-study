# projects_further — 교재 이후, 석사 수준까지

교재(chap02~12)와 [projects/](../projects/README.md)(P1~P7)를 마친 뒤에 이어 가는 2년짜리 학습 계획이다.
목표는 **비전 전공 석사 수준**: 실무로 아는 기하(정적 공차보정)를 이론으로 다지고,
옆 팀의 온라인 캘리브레이션과 인식팀의 딥러닝 인식까지 넓힌 뒤, 내 업무 문제로 논문급 프로젝트를 완주한다.

```
출발점: 비전 비전공 · AVM 정적 공차보정 실무 수년
        (차량 고정 → 타겟 영상좌표 ↔ 월드좌표 매칭 → 호모그래피 분해 → 외부 파라미터)
도착점: 기하 축(캘리브레이션·VO) + 학습 축(딥러닝 인식)을 모두 갖추고,
        논문을 읽고 재현하고 실험을 설계해 보고서로 쓸 수 있는 상태
```

> **전제 (바뀌면 기간을 다시 잡는다)**
> - 주 8~10시간, 총 약 21개월 (+ 교재 마무리 약 3개월)
> - 기하 축(Phase 1~3)을 먼저, 학습 축(Phase 4)을 나중에. 인식 쪽이 급하면 Phase 3과 4의 순서를 바꾼다.
> - 업무 데이터를 못 쓰면 합성 데이터와 공개 데이터셋(KITTI, WoodScape, PS2.0)으로 대체한다.

## Phase 1. 수학 기반 + 내 업무 재구현 (3개월)

**목표:** 지금 쓰는 호모그래피 분해 방식의 **원리와 한계를 숫자로** 설명한다.

### 학습 체크리스트
- [ ] 선형대수: SVD, 영공간(null space), 최소제곱, 조건수(condition number)
- [ ] DLT로 호모그래피 추정 유도 + 좌표 정규화(Hartley normalization)가 왜 필요한지
- [ ] 호모그래피 분해: H = K[r1 r2 t] 에서 R, t 복원, 회전 행렬 직교화(SVD로 가장 가까운 회전 찾기)
- [ ] 회전 표현: 회전 행렬, 오일러 각(짐벌락), 축-각(Rodrigues), 쿼터니언, SO(3) 기초
- [ ] 비선형 최소제곱: Gauss-Newton, Levenberg-Marquardt, 야코비안(Jacobian) 직접 유도
- [ ] 강건 추정: RANSAC, Huber/Cauchy 손실
- [ ] 확률: 가우시안 잡음 전파, 공분산, 추정값의 불확실성

### 자료
- Gilbert Strang, MIT 18.06 선형대수 (YouTube)
- Barfoot, *State Estimation for Robotics* (무료 PDF) — 회전, 비선형 최적화 장
- Hartley & Zisserman, *Multiple View Geometry* 4장 (호모그래피 추정)

### 산출물
- [ ] **F1-1 `f1_1_homography_calib`** — numpy로 직접 구현
  - [ ] DLT 호모그래피 (정규화 포함) → OpenCV `findHomography` 와 비교
  - [ ] 호모그래피 분해 → 외부 파라미터 (R, t)
  - [ ] LM으로 재투영 오차 최소화 정밀화 → 분해만 했을 때와 오차 비교
  - [ ] 테스트: 합성 데이터(정답 R, t를 알고 만든 점)로 복원 오차 검증
- [ ] **F1-2 `f1_2_sensitivity`** — 몬테카를로 민감도 분석 보고서
  - [ ] 타겟 영상 좌표에 ±0.5px 잡음 → roll/pitch/yaw/높이 오차 분포
  - [ ] 타겟 배치(개수, 간격, 카메라와의 거리)를 바꿔 가며 비교
  - [ ] 결론: "어떤 배치가 어떤 각도 오차에 강한가" 를 표와 그래프로
- [ ] 논문/자료 요약 4편 이상

**완료 기준:** 기준 ①②를 2점 이상. F1-2 결과를 팀에 설명할 수 있다.

### 진행 체크리스트
- [ ] 주제 확정 + 한 문단 문제 정의 ("무엇이, 어떤 조건에서, 얼마나 나쁜가")
- [ ] 관련 연구 조사 10편 이상, 비교표
- [ ] 베이스라인 구현 (기존 방법 또는 현재 업무 방식)
- [ ] 제안 방법 구현
- [ ] 실험 설계: 데이터셋, 지표, 비교 대상, ablation 항목을 미리 정의
- [ ] 실험 + 실패 분석
- [ ] 보고서 초안 → 동료 리뷰 → 수정

## 2. 공통 습관 (전 기간)

| 습관 | 방법 | 이유 |
|---|---|---|
| 유도 → 구현 → 라이브러리 비교 | 종이에 유도, numpy 구현, OpenCV/라이브러리와 숫자로 비교 (`cvkit.compare`) | 원리 이해 + 라이브러리를 믿을 근거 |
| 합성 데이터로 먼저 검증 | 정답을 알고 만든 데이터로 알고리즘 테스트 → 실제 데이터 | 버그와 방법의 한계를 분리 |
| 논문 루틴 | 2주에 1편, `papers/` 에 1쪽 요약 (§4 템플릿) | 기준 ⑤ |
| 재현 우선 | 새 방법은 공개 코드의 숫자부터 재현하고 나서 바꾼다 | 연구 실력의 절반은 재현 능력 |
| 기록 | `study-notes/` 에 개념 노트, `projects_further/` 에 산출물 | 그대로 포트폴리오 |
| 사내 연결 | Phase 3 이후 옆 팀 공유, 분기마다 팀 세미나 1회 | 가르치면 이해가 완성되고 평판이 쌓인다 |
| 분기 점검 | §0 점검표 채우기, 밀리면 범위를 줄이고 기간은 지킨다 | 2년짜리 계획은 점검 없이는 흐지부지된다 |

### 선택지: 실제 석사 과정

회사가 야간·주말 대학원이나 산학 장학을 지원하면, Phase 1~2를 마친 뒤 지원을 검토한다.
Phase 5 주제가 그대로 학위 논문 주제가 될 수 있다. 독학은 실력을 만들고, 학위는 그 실력을 회사 밖에서도 인정받게 해 준다.
